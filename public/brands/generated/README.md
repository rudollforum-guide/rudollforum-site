# Декоративные эмблемы каталога

Эмблемы созданы для оформления справочника Rudollforum и не являются официальными логотипами брендов.

- Файлы в папках категорий имеют размер 128×128 px и используются карточками каталога.
- Исходные версии 512×512 px находятся в `source/`.
- `manifest.json` содержит точное соответствие названия бренда, листа, позиции и обоих файлов.
- Старые SVG в корне сохранены для совместимости, но каталог их больше не использует.

Эмблемы извлекаются из предоставленных листов скриптом `scripts/extract-brand-emblems.mjs`.
Целые листы не публикуются и не используются на страницах сайта.

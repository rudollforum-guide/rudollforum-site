# Rudollforum

Русскоязычный информационный справочник о выборе, покупке, эксплуатации,
уходе, хранении и ремонте силиконовых и TPE-кукол.

Сайт предназначен только для совершеннолетней аудитории.

## Технологии

- Next.js и React;
- vinext и Vite;
- Cloudflare Workers;
- TypeScript.

## Локальный запуск

Требуется Node.js версии 22.13.0 или новее.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Локальная конфигурация хостинга в `.openai/` не публикуется. При её отсутствии
проект собирается без подключений D1 и R2.

## Важные материалы

PDF-руководство и изображения из `public/` являются частью сайта и необходимы
для корректной работы опубликованной версии.

## Правовой статус

Rudollforum — независимый информационный справочник. Проект не принимает
оплату и не оформляет заказы.
